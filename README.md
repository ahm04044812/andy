# 노래하는 피아노

브라우저에서 바로 쓰는 피아노 앱이에요. `index.html` 하나만 열면 돼요 (설치 없음).

- **노래 제목 검색 → 자동 연주**: 작은 별, 나비야, 떴다 떴다 비행기, 곰 세 마리, 생일 축하합니다, 환희의 송가, 징글벨, 런던 다리, 어메이징 그레이스, 달빛(드뷔시, 첫 부분), 엘리제를 위하여
- **양손 화음 연주**: 오른손은 멜로디 아래에 화음 음을 겹쳐 치고, 왼손은 베이스와 화음을 동시에 눌러요 (4/4는 베이스-화음-5도-화음, 3/4는 왈츠). "멜로디 + 간단 반주", "멜로디만"으로 바꿀 수 있어요
- **직접 입력**: 목록에 없는 노래는 계이름(`도레미 솔2 | 높은도`)이나 음이름(`C4 D4 E4`)으로 적으면 연주해요. 저장도 돼요
- **녹음**: 건반을 치고 녹음을 끝내면 피아노가 그대로 다시 들려줘요
- 마우스·터치·컴퓨터 키보드(`A S D F G H J K` = 도~도, `Z`/`X` 옥타브)로 직접 칠 수 있어요
